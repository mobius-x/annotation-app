# Аннотатор текста — Text Annotator

> Легкий, client-only инструмент для аннотирования любого `.txt` файла и экспорта оригинала + заметок в **один файл**. Без бэкенда, без регистрации, работает оффлайн.

### Зачем это?

В чистом `.txt` нет слоя заметок. Обычно люди делают так:
- `original.txt` + `notes.txt` отдельно → теряется связь
- Конвертируют в Word/PDF → ломается plain-text workflow
- Используют Obsidian/Notion → привязка к платформе

**Этот аннотатор решает:**
1. Оригинал остается нетронутым (non-destructive)
2. Аннотации хранятся как слой с оффсетами `start/end`
3. Экспорт в один файл в 12+ форматах — от Markdown до DOCX и Pandoc

### Основные функции (v1)

- **Загрузка:** Drag & Drop `.txt` или вставка из буфера. Демо-текст (Толстой) по умолчанию.
- **Выделение:** Выдели мышкой любой фрагмент → появляется кнопка «Добавить заметку».
- **Подсветка:** Фрагмент подсвечивается желтым `#fef08a` с бейджем-номером. Hover — темнее.
- **Правая панель:** Список заметок, сортировка по позиции в тексте, редактирование, удаление, счетчик символов, строка/позиция, очистка всех.
- **Защита:** Запрет пересекающихся аннотаций (в v2 будет режим слоев).
- **Статистика:** Символы, строки, слова, количество заметок в header/footer.
- **Темная тема:** Автоматически через `prefers-color-scheme`.
- **Toast-уведомления:** Обратная связь на каждое действие.

### Экспорт — ключевая фича

Все экспорты скачивают **один файл** где есть и оригинал, и заметки.

| Формат | Файл | Для чего |
|---|---|---|
| **Markdown** | `аннотации.md` | Obsidian, Notion, GitHub, VS Code. Сноски `[^1]` + блок `> 📝` |
| **HTML** | `аннотированный_текст.html` | Красивый standalone документ с `<mark>` и `<aside>` |
| **Combined TXT** | `комбинированный.txt` | Человеко-читаемый лог для git/diff |
| **JSON** | `аннотации.json` | Машиночитаемый, для Python/pandas |
| **CriticMarkup** *(v1.1)* | `.md` | `{++добавление++} {--удаление--} {~~старое~>новое~~}` для писателей |
| **Pandoc JSON** *(v1.5)* | `.pandoc.json` | Конвертация в DOCX/PDF/EPUB одной командой |
| **DOCX** *(v1.5)* | `.docx` | Word с реальными комментариями |
| **W3C Web Annotation** | `.jsonld` | Совместимость с Hypothesis.is |
| **CSV** | `.csv` | Excel, анализ |
| **TEI XML** | `.xml` | Академия, Digital Humanities |

Подробная спека каждого формата — в `SPECIFICATION_FULL.md`.

### Как пользоваться

1. **Загрузи текст:** Кнопка «Загрузить .txt» в header или «Вставить текст»
2. **Выдели:** Проведи мышкой по фрагменту (минимум 2 символа)
3. **Добавь заметку:** Клик «Добавить заметку» в попапе → заметка появится справа
4. **Напиши:** В правой панели введи текст заметки (поддерживает многострочный)
5. **Экспортируй:** Внизу выбери формат: Markdown / HTML / TXT / JSON

**Горячие клавиши (планируется в v1.1):**
- `n` — новая заметка из текущего выделения
- `j/k` — следующая/предыдущая заметка
- `Ctrl+Z / Ctrl+Shift+Z` — undo/redo

### Модель данных (упрощенно)

```ts
type Annotation = {
  id: string;       // ULID
  quote: string;    // срез оригинала
  start: number;    // offset начала
  end: number;      // offset конца
  note: string;     // тело заметки
}

// v2 расширенная:
// + type, tags[], color, status, prefix/suffix для robust anchoring
```

Логика выделения: `TreeWalker(SHOW_TEXT)` → суммирует длины до `anchorNode` → получает оффсеты. Проверка пересечений: `!(end <= a.start || start >= a.end)`.

### FAQ

**Q: Сохранится ли файл после перезагрузки?**
A: В v1 — нет. В v1.1 будет autosave в localStorage. Сейчас используй экспорт в JSON чтобы не потерять.

**Q: Можно ли редактировать оригинал?**
A: В v1 — только через замену файла (загрузка нового сбрасывает аннотации). В v2 будет редактирование с пересчетом оффсетов через diff.

**Q: Поддержка больших файлов?**
A: Тестировалось до ~500 КБ / 100k слов. Для >10 MB будет Web Worker + виртуализация.

**Q: Как импортировать обратно?**
A: В v1 — только JSON. В v1.5 — MD, CriticMarkup, DOCX, HTML.
