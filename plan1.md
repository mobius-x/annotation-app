# План завершения Annotator по спецификации v1.1

Сверка выполнена по `Annotator-SPEC-v1.1.md` и коду. Статус отражает наличие реализации, а не прохождение полного ручного приёмочного тестирования.

## Что уже реализовано

- Портативная среда разработки, фиксированные версии зависимостей, сборка Electron/Vite/Svelte.
- Безопасная основа Main/Preload/Renderer: ограниченный IPC с Zod-валидацией, контекстная изоляция, sandbox, CSP, ограничение доступа к путям, запрет незапрошенных разрешений и внешней навигации.
- Многокорневый проводник: открытие папок и workspace, раскрытие подкаталогов, список поддерживаемых файлов, русская естественная сортировка, фильтрация служебных файлов, обнаружение sidecar-аннотаций и конфликта форматов.
- CodeMirror-редактор, вкладки и базовые горячие клавиши; чтение/запись текста, распространённых кодировок, BOM и переводов строк.
- Создание, редактирование, удаление, фильтрация, поиск и навигация по аннотациям; типы, теги, решённость, orphan-группа, Markdown заметок.
- StateField для диапазонов, обновление привязок при правке текста, сохранение аннотации при удалении её диапазона; Focus view с запретом редактирования текста и ограниченным копированием; виртуализированный Outline.
- Форматы JSON и Markdown sidecar, проверка диапазонов, восстановление цитат, orphan-аннотации, обработка пересечений диапазонов в Markdown и тесты round-trip/property-based.
- Атомарная запись и резервные копии sidecar, снимки восстановления, наблюдение открытых файлов, проверка расхождения исходника и аннотированной копии с явным применением текста к исходнику.
- Экран настроек с расширенной схемой и неизвестными extension-ключами; отдельные семейства шрифтов, параметры редактора/панели, Focus view, цветов аннотаций, системной темы, сглаживания, автосохранения и резервирования.
- Двенадцать встроенных тем, пользовательские JSON-темы с проверкой схемы и наследованием, системное переключение и тесты контраста текста для обычной/активной подсветки.
- Список шрифтов через `queryLocalFonts()` с запасным списком и ручным вводом; preview текста.
- Реестр команд, поиск/палитра, пользовательские сочетания и двухшаговые цепочки, конфликтные префиксы, Ctrl+колесо и Ctrl+0.

Проверки 21.10.2026: `npm run typecheck` — 0 ошибок и предупреждений; `npm test` — 50 тестов в 12 файлах пройдены; `npm run build` — успешно с проверкой контраста; `npm run package:win:dir` — успешно, `app/release/win-unpacked` создан. Упакованная сборка с чистым профилем создала Chromium data и записала `settings.json`; выбор темы Solarized Light поменял вычисляемые цвета UI, затем Dracula была восстановлена. 10-минутный мониторинг TCP процесса и дочерних процессов (проверка каждые 2 секунды) не выявил внешних соединений. Benchmark: текст 5 135 360 байт + sidecar с 5 000 аннотациями открылся примерно за 527 мс до появления счётчика; синтетическая прокрутка через `requestAnimationFrame` дала 60,3 FPS для редактора и 59,1 FPS для панели. Эти результаты подтверждают только открытие и scripted scroll в данном smoke-тесте, не запуск ≤2 с, ввод <50 мс, создание аннотации <100 мс, реальную ручную прокрутку либо idle-память. Автоматизация ввода не дала валидных данных; несколько пробных символов попали в тестовый файл до остановки приложения. Тестовые рабочие файлы, профиль `data` и временные каталоги удалены.
