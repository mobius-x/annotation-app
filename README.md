# Annotator

Портативное desktop-приложение для чтения и аннотирования текстовых файлов. Исходные `.txt` и `.md` хранятся отдельно от заметок: при добавлении первой аннотации создаётся соседний файл `имя.annot.json`. Существующий `имя.annot.md` также можно открыть и редактировать; если рядом лежат оба формата аннотаций, откройте нужный sidecar-файл напрямую.

## Запуск

В корне проекта откройте `cmd.exe`, активируйте локальную среду и запустите приложение:

```bat
call env.cmd
npm ci
npm run dev
```

Node.js, Git, npm-кэш, временные файлы Electron и его бинарники размещаются в `.tools` и `.cache` внутри проекта. Системная установка Node.js не требуется. Для production-сборки интерфейса выполните `npm run build`; для создания Windows-папки приложения — `npm run package:win:dir`.

## Основные действия

- **Папка** — открыть рабочую папку; дерево раскрывается и показывает `.txt` и `.md`. В нижней панели «Структура» собраны аннотации с номерами строк; выберите строку, чтобы перейти к цитате. Список можно свернуть.
- **Открыть** — открыть отдельный текстовый файл во вкладке. Открытые документы сохраняют собственные изменения и состояние режима фокуса; переключайтесь нажатием на вкладку или Ctrl+Tab. Закрытие — ×, средняя кнопка мыши или Ctrl+W; для изменённого документа приложение предложит сохранить, отбросить изменения или отменить закрытие.
- Выделите текст и нажмите **＋ Аннотация** (Ctrl+Shift+A), выберите тип и добавьте заметку. После создания поле заметки получает фокус; Ctrl+Enter подтверждает ввод.
- Нажмите **Сохранить** (Ctrl+S). Исходник остаётся нетронутым, аннотации записываются в соседний `.annot.json` либо в уже открытый `.annot.md`.
- Двойной щелчок по заметке включает её редактирование; Markdown в карточке очищается перед отображением.
- Аннотации без диапазона находятся в отдельной группе «Без привязки»: их можно повторно найти по цитате, связать с текущим выделением или удалить.
- Панель аннотаций поддерживает поиск, фильтр по типу, скрытие решённых заметок и добавление тегов. В фокусе списка используйте стрелки для навигации, Enter для редактирования, Delete для удаления и Space для переключения статуса «решено».
- В ⚙ «Настройки» можно выбрать тему (Dracula, GitHub Light/Dark, Nord), шрифт и размер редактора; настройки хранятся в `userData/settings.json`.
- Для открытых документов отслеживаются внешние изменения исходника и sidecar-аннотаций. Приложение предложит перезагрузить файл или оставить текущую версию; собственные сохранения не вызывают это предупреждение.
- Если рядом с исходником лежат оба sidecar-файла (`.annot.json` и `.annot.md`), дерево показывает предупреждение, а при открытии исходника можно выбрать формат; второй файл остаётся нетронутым.
- Если текст аннотированной копии расходится с исходником, в статус-баре появляется команда «Применить». Она заменяет исходник только после подтверждения и сначала создаёт рядом резервную копию `.bak`, сохраняя кодировку и переводы строк.
- В статус-баре также отображаются текущая строка и столбец курсора; число аннотаций форматируется с русским склонением.
- **Новый**, Ctrl+N; **Сохранить как…**, Ctrl+Shift+S; поиск — Ctrl+F; режим фокуса — F9. В режиме фокуса текст доступен только для чтения, чтобы нельзя было случайно удалить скрытый фрагмент.

## Проверки

```bat
npm run typecheck
npm test
npm run build
```

Формат JSON проверяется по схеме: неверные и выходящие за границы диапазоны не открываются частично. Markdown sidecar использует YAML front matter, экранирование зарезервированных последовательностей и сноски; пересекающиеся диапазоны сериализуются сегментами и склеиваются при чтении. При загрузке диапазоны восстанавливаются по цитате и контексту. Установленные версии зафиксированы в `app/package-lock.json`.
