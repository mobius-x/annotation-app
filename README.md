# Annotator

Портативное desktop-приложение для чтения и аннотирования текстовых файлов. Исходные `.txt` и `.md` хранятся отдельно от заметок: при добавлении первой аннотации создаётся соседний файл `имя.annot.json`.

## Запуск

В корне проекта откройте `cmd.exe`, активируйте локальную среду и запустите приложение:

```bat
call env.cmd
npm ci
npm run dev
```

Node.js, Git, npm-кэш, временные файлы Electron и его бинарники размещаются в `.tools` и `.cache` внутри проекта. Системная установка Node.js не требуется. Для production-сборки интерфейса выполните `npm run build`; для создания Windows-папки приложения — `npm run package:win:dir`.

## Основные действия

- **Папка** — открыть рабочую папку; дерево раскрывается и показывает `.txt` и `.md`.
- **Открыть** — открыть отдельный текстовый файл.
- Выделите текст и нажмите **＋ Аннотация** (Ctrl+Shift+A), выберите тип и добавьте заметку.
- Нажмите **Сохранить** (Ctrl+S). Исходник остаётся нетронутым, аннотации записываются в соседний `.annot.json`.
- Двойной щелчок по заметке включает её редактирование; Markdown в карточке очищается перед отображением.
- **Новый**, Ctrl+N; **Сохранить как…**, Ctrl+Shift+S; поиск — Ctrl+F; режим фокуса — F9.

## Проверки

```bat
npm run typecheck
npm test
npm run build
```

Формат JSON проверяется по схеме: неверные и выходящие за границы диапазоны не открываются частично. При загрузке диапазоны восстанавливаются по цитате и контексту. Установленные версии зафиксированы в `app/package-lock.json`.
