# Annotator

Портативное desktop-приложение для чтения и аннотирования текстовых файлов. Исходные `.txt` и `.md` хранятся отдельно от заметок: при добавлении первой аннотации создаётся соседний файл `имя.annot.json`. Существующий `имя.annot.md` также можно открыть и редактировать; если рядом лежат оба формата аннотаций, откройте нужный sidecar-файл напрямую.

## Запуск

В корне проекта откройте `cmd.exe`, активируйте локальную среду и запустите приложение:

```bat
call env.cmd
npm ci
npm run dev
```

Node.js, Git, npm-кэш, временные файлы Electron и его бинарники размещаются в `.tools` и `.cache` внутри проекта. Системная установка Node.js не требуется. Для production-сборки интерфейса выполните `npm run build`; для создания Windows-папки приложения — `npm run package:win:dir`.

## Основные действия

- **Папка** — открыть одну или несколько корневых папок. Кнопка `＋` в проводнике добавляет корневую папку. Последние корни и открытые вкладки автоматически восстанавливаются при запуске. Недоступные корни остаются в дереве с кнопкой «Повторить». Дерево раскрывается и показывает `.txt` и `.md`. Контекстное меню строки и кнопка `⋯` позволяют создавать файлы и папки, переименовывать их (F2), перемещать в корзину (Delete), копировать путь и открывать расположение в Проводнике Windows. Выберите несколько строк с Ctrl/Shift и перетащите их на папку, файл или корень; удерживайте Ctrl при сбросе, чтобы копировать. При конфликте имён можно заменить элемент, оставить оба с суффиксом или отменить, а выбор можно применить ко всем конфликтам. Наведение на папку раскрывает её через 600 мс. Ctrl+Z отменяет последнюю файловую операцию, если фокус находится в дереве (до 20 действий; удаление в корзину не отменяется). Перемещение и копирование включают связанные sidecar-файлы и обновляют `source`; межтомовое перемещение сначала проверяет копию. При переименовании исходника sidecar-файлы также переименовываются, а `source` обновляется. В нижней панели «Структура» собраны аннотации с номерами строк; выберите строку, чтобы перейти к цитате. Список можно свернуть.
- **Открыть** — открыть отдельный текстовый файл во вкладке. Открытые документы сохраняют собственные изменения и состояние режима фокуса; переключайтесь нажатием на вкладку или Ctrl+Tab. Закрытие — ×, средняя кнопка мыши или Ctrl+W; для изменённого документа приложение предложит сохранить, отбросить изменения или отменить закрытие.
- Выделите непустой фрагмент текста и нажмите появившуюся рядом кнопку **＋ Аннотация**, кнопку на панели или Ctrl+Shift+A. После создания поле заметки получает фокус; Ctrl+Enter подтверждает ввод. Пробельное выделение не запускает создание, а режим IME не показывает плавающую кнопку.
- Нажмите **Сохранить** (Ctrl+S). Исходник остаётся нетронутым, аннотации записываются в соседний `.annot.json` либо в уже открытый `.annot.md`.
- Двойной щелчок по заметке включает её редактирование; Markdown в карточке очищается перед отображением.
- Аннотации без диапазона находятся в отдельной группе «Без привязки»: их можно повторно найти по цитате, связать с текущим выделением или удалить.
- Панель аннотаций поддерживает поиск, фильтр по типу, скрытие решённых заметок и добавление тегов. В фокусе списка используйте стрелки для навигации, Enter для редактирования, Delete для удаления и Space для переключения статуса «решено».
- В ⚙ «Настройки» доступны 12 встроенных тем и импорт пользовательских JSON-тем, следование системной схеме, отдельные шрифты и размеры для интерфейса, редактора и аннотаций, цвета и интенсивность подсветки, параметры Focus view, панели и автосохранения. Список локальных шрифтов запрашивается через `queryLocalFonts()`; если API недоступен, остаются встроенный список и ручной ввод. Настройки хранятся в `userData/settings.json`.
- Список аннотаций виртуализирован с измерением высот карточек, чтобы сохранять отзывчивость на больших документах. Кнопка кодировки в строке состояния позволяет переоткрыть документ в UTF-8, Windows-1251, UTF-16, KOI8-R или ISO-8859-1; для несохранённого документа перед этим запрашивается подтверждение.
- Панель команд открывается через Ctrl+Shift+P; сочетания настраиваются в ⚙ «Настройки», поддерживаются цепочки клавиш и сопоставление по физическому коду для русской раскладки. Ctrl+колесо меняет размер текста, Ctrl+0 сбрасывает масштаб.
- Для открытых документов отслеживаются внешние изменения исходника и sidecar-аннотаций. Приложение предложит перезагрузить файл или оставить текущую версию; собственные сохранения не вызывают это предупреждение.
- Если рядом с исходником лежат оба sidecar-файла (`.annot.json` и `.annot.md`), дерево показывает предупреждение, а при открытии исходника можно выбрать формат; второй файл остаётся нетронутым.
- Если текст аннотированной копии расходится с исходником, в статус-баре появляется команда «Применить». Она заменяет исходник только после подтверждения и сначала создаёт рядом резервную копию `.bak`, сохраняя кодировку и переводы строк.
- В статус-баре также отображаются текущая строка и столбец курсора; число аннотаций форматируется с русским склонением.
- **Новый**, Ctrl+N; **Сохранить как…**, Ctrl+Shift+S; поиск — Ctrl+F; режим фокуса — F9. В режиме фокуса текст доступен только для чтения, чтобы нельзя было случайно удалить скрытый фрагмент.

## Проверки

```bat
npm run typecheck
npm test
npm run check:contrast
npm run build
```

Формат JSON проверяется по схеме: неверные и выходящие за границы диапазоны не открываются частично. Markdown sidecar использует YAML front matter, экранирование зарезервированных последовательностей и сноски; пересекающиеся диапазоны сериализуются сегментами и склеиваются при чтении. При загрузке диапазоны восстанавливаются по цитате и контексту. Установленные версии зафиксированы в `app/package-lock.json`.

Последняя локальная проверка (21.10.2026): `npm run typecheck` прошёл без ошибок и предупреждений; `npm test` — 50 тестов; `npm run build` и Windows x64 `npm run package:win:dir` завершились успешно. Эти результаты не заменяют ручное прохождение 22 сценариев приёмки и замеры NFR; для них ниже в спецификации ведётся отдельный статус.

Сборка `dir` была запущена с новой пустой папкой `data` рядом с `Annotator.exe`; профиль Chromium и файл `settings.json` после вызова штатного сохранения появились внутри этой папки. В десятиминутном мониторинге TCP-соединений процесса и дочерних процессов (опрос каждые 2 секунды) внешних соединений не обнаружено. Это не заменяет ручное прохождение остальных сценариев приёмки и замеры NFR; временные пользовательские данные проверки удалены.
